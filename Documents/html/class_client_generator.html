Detailed Description

This generates the clients for the day. It generates ClientData, which is solely data. The game object is created with the ClientSpawner. Results depend on game seed, day number and upgrade bonus. We track used requests, which are requests that have been answered or ones that are returning.

This is done by shuffling requestIds using the game seed in a 'deck'. The start of a round deals the first N requests in the deck that aren't in the used list. Looks come from the seed and request ID, so returning clients can be built off of those.
