Detailed Description

NPC that helps the client conduct research by providing methodologies. Occupies a cubicle in the research firm. Empty position means not purchased.

Prefab component for researcher. This holds no data or logic, ResearcherData.cs holds all of that. This component displays what is in ResearcherData.cs. The prefab is the same for all researchers. Bind() applies the ResearcherData to this object, making each Researcher different.
