Detailed Description

UpgradeDefintion allows for modular upgrades to be added. This sets up one upgrade the player can buy and saves it as an asset.

To make an upgrade: Create > Research Frenzy > Upgrade, then fill in data points Then, add to Upgrades list in the controller
